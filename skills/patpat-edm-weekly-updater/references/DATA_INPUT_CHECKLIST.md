# Weekly Input Checklist

For each new week, provide:

1. Baseline HTML
- Latest approved dashboard html in output folder.

2. New week source files
- Emarsys manual weekly file
- Emarsys automation weekly file
- Attribuly weekly file

3. File sanity checks
- manual/auto file has `Launch date` and total row (`total`)
- attribuly file has:
  - `Clicks(UV)`
  - `Attribuly tracked conversions`
  - `Attribuly tracked conversion value`
  - `Campaign(Source/Medium)`
  - `Medium`

4. Week range confirmation
- explicit start/end date (e.g. `2026-03-29 ~ 2026-04-04`)

5. Optional policy changes
- any whitelist changes
- any metric formula changes
- any new theme/flow mapping changes
